# トラブルシューティング

## 偽リプが表示されない

以下を順番に確認してください。

1. `chrome://extensions` で「X インプレゾンビ表示」が **有効** になっているか確認します。
2. 設定ページを開き、**「拡張を有効にする」** がオンになっているか確認します。
3. アクセスしているページが `https://x.com/ユーザー名/status/数字` 形式のポスト詳細ページか確認します（ホームタイムライン・検索ページ等では動作しません）。
4. ページを強制リロード（`Cmd+Shift+R` / `Ctrl+Shift+R`）してみます。
5. `extension/dist/` フォルダが存在するか確認します。存在しない場合は `npm run build` を実行してください。

## LLM が動作しない・プリセットにしか切り替わらない

1. 設定で **「LLM で生成する」** がオンになっているか確認します。
2. **API キー** が正しく入力・保存されているか確認します（「保存」ボタンを押す必要があります）。
3. **API ベース URL** が正しいか確認します（末尾は `/v1` まで含めてください）。
4. 使用しているモデル名がエンドポイントで対応しているか確認します。
5. OpenAI API の場合、クォータや残高を確認してください。

> LLM 呼び出し失敗時は自動的にプリセットへフォールバックします。これは正常な動作です。

## スクロール後や画面遷移後に偽リプが消える

`MutationObserver` が自動的に再挿入を試みます。  
1 分以内に 45 回の再試行を超えるとオブザーバが停止します。その場合はページをリロードしてください。

X の UI が大きく変更された場合は、`extension/src/content.ts` の `extractMainPostText()` や挿入位置のセレクタが壊れている可能性があります。

## Chrome 起動時に警告ダイアログが表示される

> 「デベロッパーモードの拡張機能を無効にする」

未署名の野良拡張をデベロッパーモードで読み込んでいるため避けられません。  
**「拡張機能を有効のままにする」** を選択してください。詳細は [インストールガイド](install.md) を参照してください。

## 偽リプのスタイルが公式と大きくズレている

X が DOM 構造または CSS を更新した可能性があります。以下を確認・修正してください。

- `extension/src/content.ts` の `extractMainPostText()` — ポスト本文を取得するセレクタ
- `extension/src/content.ts` の `findInsertAnchor()` — 挿入位置のアンカー
- `extension/styles/content.css` — テーマカラー変数（`--z-text`, `--z-secondary`, `--z-border` 等）

## 設定を保存してもすぐに反映されない

設定変更は `chrome.storage.onChanged` イベント経由でコンテンツスクリプトに即時反映されます。  
反映されない場合はページをリロードしてください。
