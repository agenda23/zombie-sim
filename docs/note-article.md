# リプのないポストを眺めていたら「自分のポストにインプレゾンビが沸いたら笑えるのにな」と思って Chrome 拡張を作ってしまった話

---

## なんでこんなものを作ったのか

「インプレゾンビ」という言葉が定着してからというもの、X を眺めるたびにあのリプたちが目に入るようになった。中身のない絵文字だけのリプ、「わかります！」と一言だけ添えたリプ、本文と 1 ミリも関係ない感謝の言葉。腹が立つような、でもどこかシュールで笑えるような、あの独特の生態系。

ある夜、いつもどおり X を眺めていて、ふと気づいた。自分のポストには、そういうものがまったく来ない。

来るどころか、まともなリプ自体がほとんどない。タイムラインにそっと放り込んだ言葉が、波紋すら立てずにひっそり沈んでいく。「いや別にバズりたいわけじゃないし」と言い訳しながら、無反応のポストを眺め続けていたそのとき、ふとこう思った。

**「自分のポストにもインプレゾンビが沸いたら、笑えるのにな」**

バズってもいないのに偽のゾンビリプが量産されているという光景、それを自分だけのローカル画面で演出できたら、なかなかシュールで面白いのではないか。誰かを傷つけるわけでもない。サーバーを改ざんするわけでもない。ただ自分のブラウザの中でだけ、インプレゾンビたちに好き放題暴れてもらう。それだけの話だ。

そのアイデアを思いついてから 3 時間後には実装が終わっていた。

まったくのクソ拡張機能である。

使い道も社会的意義も存在しない。あるのは「無リプの自分のポストをゾンビたちが囲んでいる光景を見てじわじわ笑う」というただそれだけの体験価値だ。それで十分だと思う。

---

## 何ができるのか

**X インプレゾンビ表示（ローカル演出）** は、X（旧 Twitter）のポスト詳細ページに、偽のインプレゾンビ風リプライを自分の画面だけに表示する Chrome 拡張機能です。他の人の画面は変わりません。サーバーにも影響しません。ぜんぶ自分のブラウザの中だけで完結します。

### できること

- ポスト詳細ページを開くと、元ポストの直下に偽リプが自動的に挿入されます
- 偽リプの文言は **LLM API（OpenAI 互換）** を使って元ポストの内容に沿ったゾンビっぽい文章を生成できます
- API を持っていなくても、**プリセット 37 種**からランダムに選んで表示されます（「いいね押しといた！」「これは刺さるわ…」「神ポスト来た」などなど）
- X のダーク／ライトテーマに自動追従し、公式のリプ行と近い見た目で表示されます
- X が内部的にページを再描画してゾンビが消えても、一定時間内に自動で復帰します

### できないこと

- 実際に X へリプを投稿すること（あくまでローカルの見た目だけです）
- 他の人の画面を変えること
- なんらかの実用的な目的を果たすこと

## 導入方法（取り扱い説明書）

Chrome Web Store には公開していません。開発者モードで手動で読み込む「野良拡張」です。

### 用意するもの

- **Node.js 18 以上**
- **Chrome 120 以上**

### 手順

**① ファイルを入手する**

GitHub の [Releases ページ](https://github.com/agenda23/zombie-sim/releases) から最新版の ZIP をダウンロードして、適当なフォルダに展開してください。

**② ビルドする**

展開したフォルダをターミナルで開いて、以下の 2 行を実行します。

```
npm install
npm run build
```

しばらく待つと `extension/dist/` というフォルダが生成されます。これが Chrome に読み込む拡張機能の本体です。

**③ Chrome に読み込む**

1. Chrome のアドレスバーに `chrome://extensions` と入力して開きます
2. 右上にある **「デベロッパーモード」** のスイッチをオンにします
3. 表示された **「パッケージ化されていない拡張機能を読み込む」** をクリックします
4. さきほど生成した `extension/dist/` フォルダを選択します

「X インプレゾンビ表示（ローカル演出）」が一覧に表示されれば完了です。X のポスト詳細ページを開いてみてください。

### 設定

拡張機能のアイコンを右クリック →「オプション」で設定ページを開けます。

API キーの設定は任意です。設定しなくてもプリセット文言（37 種類）でそれなりに動きます。LLM 生成を使いたい場合は、お持ちの OpenAI 互換 API キーを入力してください。偽リプの件数（1〜50）も自由に変えられます。

### Chrome 起動時の警告について

デベロッパーモードで読み込んだ拡張機能がある場合、Chrome を起動するたびに「デベロッパーモードの拡張機能を無効にしますか？」というダイアログが出ます。**「拡張機能を有効のままにする」** を選んでください。野良拡張の宿命なのでご了承ください。

いくつか注意点をまとめておきます。

**動作環境について**
思いつきでざっくり作ったので、自分の環境（Mac + Chrome）でざっと動くことを確認した程度です。細かいテストはしていません。Windows や他のブラウザでの動作は未確認です。

**LLM API 機能について**
LLM 生成の機能はとりあえず実装しただけで、自分では実際にほとんど触っていません。動くとは思いますが、想定外の挙動があっても不思議ではないです。

**使用は自己責任でお願いします。**
野良拡張なので Chrome の署名検証を通っていません。何か問題があっても責任は負いかねます。

GitHub リポジトリは現在非公開にしています。コードを見たい方は、この記事のコメントか X の DM でひと声かけてもらえればこっそりお見せします。
