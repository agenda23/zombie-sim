# 設定ガイド

設定ページは以下のいずれかの方法で開けます。

- ツールバーの拡張アイコンを右クリック → **「オプション」**
- `chrome://extensions` → 「X インプレゾンビ表示」→ **「詳細」** → **「拡張機能のオプション」**

## 設定項目

### 拡張を有効にする

ON のとき、ポスト詳細ページに偽リプを挿入します。  
OFF にすると挿入が止まり、すでに表示されている偽リプノードは即座に除去されます。

既定値: **ON**

---

### LLM で生成する

ON かつ API キーが設定されている場合、LLM API を使って元ポストの内容に沿ったリプ文を生成します。  
OFF の場合はプリセット文言のみ使用します。

既定値: **OFF**

---

### API キー

OpenAI 互換エンドポイントの API キーを入力します。  
キーは `chrome.storage.local`（ブラウザ内）に保存され、表示中のページには渡りません。  
設定しない場合はプリセットモードで動作します。

---

### API ベース URL

OpenAI 互換 API のベース URL です。末尾 `/v1` まで入力してください。  
OpenAI を直接使う場合は既定値のままで構いません。

既定値: `https://api.openai.com/v1`

例:
- OpenAI: `https://api.openai.com/v1`
- Azure OpenAI: `https://<リソース名>.openai.azure.com/openai/deployments/<デプロイ名>` （エンドポイントに合わせて調整）
- ローカル LLM (Ollama 等): `http://localhost:11434/v1`

---

### モデル名

使用するモデルの名前です。エンドポイントが対応しているモデル名を入力してください。

既定値: `gpt-4o-mini`

---

### 偽リプ件数（1〜50）

各ポスト詳細ページに表示する偽リプの最大数です。

既定値: `5`

---

### 本文が取得できないとき

ポストの本文が DOM から抽出できなかった場合の動作を選択します。

| 選択肢 | 動作 |
|--------|------|
| すぐプリセットを使う（既定） | 本文なしで LLM を呼ばずプリセットにフォールバック |
| 空本文でも LLM を試す | 空の本文を LLM に渡して生成を試みる |

---

## API なしで使う

API キーを設定しなくても、37 種類のプリセット文言からランダムに選択した偽リプが表示されます。  
まずは API なしで動作確認することをお勧めします。

## キャッシュについて

生成したリプは URL ごとに **24 時間キャッシュ** されます。キャッシュ中は API が再呼び出しされません。  
キャッシュを即座にリセットしたい場合は、`chrome://extensions` → 「詳細」→ **「拡張機能のデータを消去」** からストレージをクリアしてください。
