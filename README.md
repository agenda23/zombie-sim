# X インプレゾンビ表示（ローカル演出）

X (Twitter) のポスト詳細ページに、自分の画面だけで偽のインプレゾンビ風リプライを表示する Chrome 拡張です。  
サーバー・他者の表示には一切影響しません。

## 必要環境

- Node.js 18 以上
- Chrome 120 以上

## ビルド

```bash
npm install
npm run build          # extension/dist/ に出力
npm run watch          # ファイル変更を監視して自動リビルド
```

## Chrome への読み込み

1. Chrome で `chrome://extensions` を開く
2. **デベロッパーモード** をオン
3. **パッケージ化されていない拡張機能を読み込む** → `extension/dist/` を選択

## 設定

拡張アイコンを右クリック → **オプション** から設定できます。

| 項目 | 説明 |
|------|------|
| LLM 有効/無効 | オフ時はプリセット文言のみ使用 |
| API キー | OpenAI 互換エンドポイントのキー |
| API ベース URL | カスタムプロキシ使用時のみ設定 |
| モデル名 | 省略時はエンドポイント既定値 |
| 偽リプ件数 | 表示する偽リプの最大数 |

API キーを設定しない場合はプリセットのみで動作します。

## 仕組み

- **対象ページ**: `https://x.com/*/status/*` のポスト詳細のみ
- **生成優先度**: キャッシュ → LLM API → プリセット（フォールバック）
- **キャッシュ**: 同一 URL への重複 API 呼び出しを 24h 抑制
- **再挿入**: X の再レンダリングで偽ノードが消えた場合は `MutationObserver` で復帰

> **注意**: 本機能はローカル演出です。スクリーンショット等で第三者を誤認させる用途は利用者の責任となります。
